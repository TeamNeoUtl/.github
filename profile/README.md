# Team NeoUtl

Team NeoUtl は多くの人に自由で快適な動画編集体験を提供したいと考えています。

## [NeoUtl](https://neoutl.taisho-guy.org)

Linux / Windows で動作する、AviUtl ライクな動画編集ソフトです。

現在はプレアルファ版です。

## [Madoka Launcher](https://madoka.taisho-guy.org)

Linux / Windows で動作する、ゆっくりMovieMaker 4 、AviUtl （ExEdit0 / ExEdit2）向けのランチャーです。

各ソフトのインスタンスを複数管理、プラグインや拡張等のバージョンを管理することができます。

## [Artisan Mod Loader]

現在非公開で開発中の、AviUtl ExEdit2 、YMM4 を抽象化する API です。

１度書けば複数のソフトで動作することを目標に開発しています。

WebAssembly Interface Type により、様々な言語に同時に対応することができます。

# Team NeoUtl

Team NeoUtl はより多くの人に自由で快適な動画編集体験を提供することを目的とし、以下のプロジェクトを遂行しています。

## NeoUtl

Linux / Windows で動作する、AviUtl ライクな動画編集ソフトです。

Qt6 版（NeoQtl）や iced 版等も非公開で試作されています。

プレアルファ版（egui 版）を公開しています。

[公式サイト](https://neoutl.taisho-guy.org) / [リポジトリ](https://github.com/TeamNeoUtl/NeoUtl) / [Zulip](https://taisho-guy.zulipchat.com/join/lz2ljlwmnz2xridgihuprspg/)

## Madoka Launcher

Linux / Windows で動作する、ゆっくりMovieMaker 4 、AviUtl （ExEdit0 / ExEdit2）向けのランチャーです。

各ソフトのインスタンスを複数管理、プラグインや拡張等のバージョンを管理することができます。

アルファ版を公開しています。

[公式サイト](https://madoka.taisho-guy.org) / [リポジトリ](https://github.com/TeamNeoUtl/Madoka-Launcher)

## Artisan Mod Loader

現在非公開で開発中の、AviUtl ExEdit2 、YMM4 を抽象化する API です。

1度書けば複数のソフトで動作することを目標に開発しています。

WebAssembly Interface Type により、様々な言語に同時に対応することができます。
